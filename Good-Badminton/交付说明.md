## 二、怎么跑（两条命令）

### 方式 A：双击脚本（推荐给老师演示）

把 mp4 文件**拖到 `一键分析.bat` 上**，或者在命令行：

```bat
cd C:\Users\13650\Desktop\badminton-hawkeye-github\Good-Badminton
一键分析.bat "C:\Users\13650\Desktop\badminton-hawkeye-github\badminton-videos-backup\demo1.mp4"
```

跑完自动打开输出目录：`outputs_upstream\<视频名>\`

### 方式 B：命令行（可控制参数）

```bat
cd C:\Users\13650\Desktop\badminton-hawkeye-github\Good-Badminton
set GB_AUTO_ACCEPT=1
..\.venv\Scripts\python.exe -u main.py ^
  --video-path "..\badminton-videos-backup\demo1.mp4" ^
  --display false --audio false ^
  --output-dir "..\outputs_upstream\demo1"
```

自动标定失败时（多场地/手持画面），直接给四角，不弹窗：

```bat
set GB_AUTO_ACCEPT=1
set GB_AUTO_CORNERS=456,399;815,340;900,678;380,678
```

### 叠加落点判罚

```bat
..\.venv\Scripts\python.exe tools\judge_from_upstream.py ^
  --run-dir "..\outputs_upstream\demo1" --mode doubles
```

→ 生成 `detect_judged.mp4`（底部显示"落点 (x,y)m 界内/界外 裕度 xx mm"）与 `judge_report.json`

## 五、已知限制（如实写，别回避）

| 限制              | 说明                                            | 应对                                          |
| --------------- | --------------------------------------------- | ------------------------------------------- |
| 需要"机位固定 + 球场完整" | 手持、多场地同框（如 `1.mp4`）自动标定会失败                    | 用 `GB_AUTO_CORNERS` 给四角，或直接跑 main.py 用鼠标点四角 |
| CPU 较慢          | 约 5.8× 实时；1039 帧要 3 分钟                        | 演示前先跑好；或换 GPU                               |
| 回放/特写镜头会被跳过     | `is_court_view` 整帧模板匹配，非球场画面不输出帧（这是设计意图，避免错标） | 正常比赛画面不受影响                                  |
| 判罚是单目估算         | 落点误差来自标定与检测，不是双目三角测量                          | 对外只讲"辅助判罚/参考"，不要讲"毫米级"                      |
