## 一、最快路径：双击启动

双击 **`启动.bat`**（在 `Good-Badminton` 文件夹里）→ 弹出「羽毛球鹰眼分析台」窗口。

> 若双击没反应，用这行命令（复制到 `Win+R` 运行框回车即可）：
> ```
> "C://Users//13650//Desktop//badminton-hawkeye-github//.venv//Scripts//pythonw.exe" "C://Users//13650//Desktop//badminton-hawkeye-github//Good-Badminton//app_gui.py"
> ```

### 三步出结果

1. **拖视频**：把 mp4/mov 拖进窗口上方的虚线框（或点「选择视频」）；
2. **点「开始分析」**：如果还没标定过，会**自动弹出标定窗口**；
3. **点球场四个角**：按提示顺序点 **左上 → 右上 → 右下 → 左下**（就是你画面里双打场地的四个角，点错按 Backspace 撤销）。
   点满四点后窗口自动关闭、分析自动开始。

等 30 秒～1 分钟（CPU 上 YOLO 约 0.25 秒/帧），右侧出现预览图，日志区显示每一步结果。

## 三、那张标定窗口怎么点

```
画面示意：
  ┌──────────────────────────┐
  │ ①左上 ●───────────● ②右上 │   ← 远端底线两端
  │       │   球场   │        │
  │       │          │        │
  │ ④左下 ●───────────● ③右下 │   ← 近端底线两端
  └──────────────────────────┘
```

要求（很重要，决定能不能判罚）：
- 点的是**双打场地的四个角**（最外侧的白线交点），不是单打线；
- **四个角都要在画面内**——如果近端底线被裁掉了，落点判罚算不准（程序会提示低置信并拒绝判罚）；
- 点完会存进 `Good-Badminton\calib_single_cam.json`，**同一机位以后不用再点**。

## 四、结果在哪看

| 内容 | 位置 |
|---|---|
| 预览图（轨迹+落点+判罚） | 窗口右侧；文件在 `视频同目录\hawkeye_out\<视频名>\preview.png` |
| 标注视频 | 同上目录 `annotated.mp4`（点界面「播放标注视频」直接打开） |
| 结构化结果 | 同上目录 `result.json`（每阶段状态、轨迹点、判罚依据） |

窗口下方的下拉/勾选框：
- **判罚模式**：双打 / 单打（决定边线用哪条）；
- **检测器**：自动（有 TrackNet CSV 就用）/ 运动检测 / YOLO；
- **仅轨迹(不判罚)**：只想看轨迹时勾上，跳过标定；
- **复用标定**：确认是同一机位同一场地时才勾；
- **手动标定球场 / 清除标定**：重做或清空标定。

## 五、命令行用法（可选）

打开终端，`cd` 到 `Good-Badminton`：

```bash
# A. 标准流程（YOLO + 时序补全），首次会自动检测球场，建议直接给四点
..\.venv\Scripts\python.exe video_pipeline.py "..\badminton-videos-backup\demo1.mp4" ^
    --corners "430,140;850,140;1030,640;250,640" --mode doubles --max-frames 200

# B. 用 TrackNetV3 结果（先跑它的推理，见 README 第十一节）
..\.venv\Scripts\python.exe video_pipeline.py "..\third_party\TrackNetV3\clip6s.mp4" ^
    --ball-csv "..\third_party\TrackNetV3\pred_clip6s\clip6s_ball.csv"

# C. 只跑合成演示（不需要视频，验证系统是否正常）
..\.venv\Scripts\python.exe video_pipeline.py --demo

# D. 一键自检
..\.venv\Scripts\python.exe selftest.py
```

`--corners` 是手动四点，格式 `左上;右上;右下;左下`（x,y 用像素坐标）。

## 六、常见问题

**Q1：日志说「标定置信度低 / 不给出落点判罚」？**
说明自动检测到的四边形只占画面一小块（子区域误拟合）。点「手动标定球场」重新点四个角即可。

**Q2：日志说「本段轨迹未跟到落地（球仍在空中）」？**
这段视频里球没被打到落地，或者中途漏检太多。把「最多处理帧数」调大、或换一段完整回合的视频。

**Q3：为什么这么慢？**
CPU 上 YOLO 约 0.25 秒/帧。想快：把帧数调小，或先跑 TrackNet 再喂 `--ball-csv`（快 12 倍）。

**Q4：换机位/换球馆了怎么办？**
点「清除标定」，下次分析会重新让你点四角。

**Q5：想拿到"球在哪一帧在哪"的原始数据？**
看 `result.json` 里的 `trajectory` 字段（帧号 + 像素坐标）。

## 七、一句话提醒

**这套系统对"拍得规矩"的视频才可靠**：固定机位、四个角都在画面内、球看得见。
不满足这些条件时，它会**拒绝判罚并告诉你原因**，而不是给你一个看着像真的的错答案。
